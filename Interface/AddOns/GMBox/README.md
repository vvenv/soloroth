# GM Box — 给本地 VMaNGOS realm 用的 GM 工具

装在 1.12.1 客户端里（`Interface/AddOns/GMBox`）。所有按钮做的事都一样：
把一条 `.` 开头的 GM 命令通过聊天发给服务端。需要 GM 账号（本 realm 的 `admin`
是 gmlevel 6），没权限的话服务端只会拒绝，不会有别的后果。

物品在 **Items**（`/gi`）。传送点在 **Teleport**（`/gt`）。五人副本的进本、
重置、地图和掉落在 **Dungeon**（`/gd`）。

## 打开

| 操作 | 说明 |
|---|---|
| `/gm` | 开关窗口 |
| **G** | 默认快捷键（第一次登录时写入，可改） |
| 小地图按钮 | 左键开关窗口 |
| `/gm help` | 帮助 |

也可以在「按键设置 → GM 工具」里改快捷键。

## 窗口

一行一组：经验倍率（全部 / 一半 / 停止）、GM 模式与隐身、god/fly/waterwalk、
全飞行点、全地图、复活、脱卡、修装、满技能、学光本职法术与天赋、移速 1/2/4/7 倍
（进游戏默认 2 倍）、加钱加等级，以及对玩家（含 bot 队友）的 `.goname`（去他那）/
`.namego`（召来）/ `.pinfo`。名字可手填，或点「取当前目标」。

最下面有一个「任意命令」输入框，任何没做成按钮的命令都能直接敲（前面的点可省）。

经验减少时，任务少给的那部分经验折成金币。倍率按角色保存在服务端。

## 注意

- 死亡 / 灵魂状态下客户端拒绝 `SAY`，GMBox 会改成密语自己，所以「复活」等按钮
  仍然可用。
- 窗口位置会记住。
