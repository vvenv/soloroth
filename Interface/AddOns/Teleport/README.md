# 传送 — 本地 VMaNGOS 的传送点

装在 1.12.1 客户端里（`Interface/AddOns/Teleport`）。点一下就把 `.tele` 或 `.go xyz`
发给服务端。需要 GM 账号；没权限的话服务端只会拒绝。

以前这是 GMBox 的「传送」页。物品在 **Items**（`/gi`），GM 工具在 **GMBox**（`/gm`）。
五人副本的进本、重置、地图和掉落在 **Dungeon**（`/gd`）。

## 打开

| 操作 | 说明 |
|---|---|
| `/gt` | 开关窗口 |
| **J** | 默认快捷键（第一次登录时写入，可改） |
| `/gt <关键词>` | 只有一个匹配就直接过去，多个就打开列表 |
| `/teleport` | 同 `/gt` |
| 小地图按钮 | 左键开关窗口 |
| `/gt help` | 帮助 |

也可以在「按键设置 → 传送」里改快捷键。

## 列表

服务端 `game_tele` 表里的 997 个地点。输入片段即可搜索（`iron` → Ironforge，
`gurub` → ZulGurub，短别名如 `brd`、`av`、`aq40` 也在里面）。中文客户端下
中文名、拼音、英文名都能搜。

- 左键 = `.tele <地名>`
- Shift+左键 = `.go xyz`（按坐标硬跳，`.tele` 名字有歧义时用它）
- 右键 = 收藏（打星，搜索框为空时排在最前）
- 底部：`go xyz` 手输坐标、`回上个点`（`.recall`，回到上次传送前的位置）、`我在哪`（`.gps`）
- 回车传送当前列表的第一条

## 世界地图

`Data_MapBounds.lua` 来自 `WorldMapArea.dbc`（只含东部王国 / 卡利姆多）。

- 已经放大到区域图时：**左键**点地图 → 出现「传送：地名」按钮
- 任意户外图：**右键**或 **Ctrl+左键** → 同样出按钮（不改变当前缩放）
- 点按钮 = 传到离点击最近的 `game_tele`（用列表里的高度，落地稳）
- 换区域或关掉地图时按钮消失；大陆总览上的普通左键仍是放大

搜索框为空时，列表显示的是收藏 + 最近用过的。从 GMBox 拆出来的第一次登录，
会把原来的收藏和最近记录拷过来（存在 `SavedVariables/Teleport.lua`）。

## 中英文

中文客户端（zhCN）下界面、地图名和聊天回显是中文，列表优先显示中文地名。
传送点的英文名保持原样（`Ironforge`、`brd`、`aq40`），因为那是 `.tele` 的键，
必须逐字传给服务端；悬停时英文名写在第二行。

## 数据是烤进插件里的

`Data_Tele.lua` 从世界数据库导出，搜索在本地完成。表名仍是生成脚本写下的
`GMBox_Tele`、`GMBox_TeleZH`、`GMBox_TelePY`。数据库变了（比如 `.tele add`
加了新传送点）就重新生成，再把生成的 `Data_Tele.lua` 拷到本目录：

```sh
~/vvenv/wow/bin/gmbox-gen-data.sh
```

脚本写到 wow 仓库的 `addons/GMBox/Data_Tele.lua`，不直接改这里。

## 注意

- 死亡 / 灵魂状态下客户端拒绝 `SAY`，插件会改成密语自己，传送仍然可用。
- 窗口位置会记住。
- 新插件要完整重启客户端才会出现，`/reload` 不够。
