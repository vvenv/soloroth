# 物品 — 本地 VMaNGOS 的物品列表

装在 1.12.1 客户端里（`Interface/AddOns/Items`）。点一下就把 `.additem`
发给服务端。需要 GM 账号；没权限的话服务端只会拒绝。

以前这是 GMBox 的「物品」页。传送在 **Teleport**（`/gt`），GM 工具在
**GMBox**（`/gm`），五人副本在 **Dungeon**（`/gd`）。

## 打开

| 操作 | 说明 |
|---|---|
| `/gi` | 开关窗口 |
| **I** | 默认快捷键（第一次登录时写入，可改） |
| `/gi <关键词或 id> [数量]` | 只有一个匹配就直接进包，多个就打开列表 |
| `/items` | 同 `/gi` |
| 小地图按钮 | 左键开关窗口 |
| `/gi help` | 帮助 |

也可以在「按键设置 → 物品」里改快捷键。

## 列表

服务端 `item_template` 里的物品，按名字或 id 搜。名字按品质染色，右侧是 id，
鼠标悬停出物品提示。「我能用」按职业、种族、需求等级和护甲类型筛掉穿不了的。

- 左键 = `.additem <id> <数量>`，数量取底部输入框（1/5/20/100 有快捷按钮）
- Shift+左键 = 只加 1 个
- 右键 = 收藏
- 回车加上当前列表的第一条

搜索框为空时，列表显示的是收藏 + 最近用过的。从 GMBox 拆出来的第一次登录，
会把原来的收藏、最近记录和数量拷过来（存在 `SavedVariables/Items.lua`）。

## 中英文

中文客户端（zhCN）下界面和聊天回显是中文，列表显示中文名（数据库
`locales_item.name_loc4`，覆盖约 89%，没有中文名的回落到英文）。
**搜索中英文都认**——`/gi 亚麻布` 和 `/gi linen cloth` 都能命中 2589。

## 数据是烤进插件里的

`Data_Items.lua` 从世界数据库导出，搜索在本地完成。表名仍是生成脚本写下的
`GMBox_Item*`。物品表变了就重新生成，再把生成的 `Data_Items.lua` 拷到本目录：

```sh
~/vvenv/wow/bin/gmbox-gen-data.sh
```

脚本会读 `config/mangosd.conf` 里的 `WowPatch`，按「不超过该补丁的最新一版」
取物品。它写到 wow 仓库的 `addons/GMBox/Data_Items.lua`，不直接改这里。

## 注意

- 死亡 / 灵魂状态下客户端拒绝 `SAY`，插件会改成密语自己，加物品仍然可用。
- 窗口位置会记住。
- 新插件要完整重启客户端才会出现，`/reload` 不够。
